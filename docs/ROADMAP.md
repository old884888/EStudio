### 雷一：CLI 命令控制 ✅（2026-08-13 交付）

**目标**：学习中心长出双手——AI 提议命令，用户在气泡里批准并看到执行过程。

```
任务清单：
☑ executor.py：subprocess 执行层（超时 60s、目录约束、stdout/stderr 实时流、exit code、输出截断 20k）
☑ 安全护栏：危险模式黑名单（rm -rf/format/shutdown/del…）、交互式命令拒绝、提权拒绝、远程拒绝
☑ 白名单机制：只读类命令（dir/ls/cat/pytest/git status…）自动放行；白名单外需批准
☑ AI 侧：estudio-cmd 围栏协议 → 模型产出 {cmd, cwd, reason}（跨 chunk 拆包免疫的流式检测）
☑ SSE 事件流：tool_propose → tool_start → tool_stream → tool_end / tool_denied
☑ 终端气泡 UI：状态徽章（自动执行/待批准/执行中/成功/失败/已拦截）、实时输出 stderr 标红、批准/拒绝按钮
☑ 命令全程写入会话存档（tool_log）+ 批准超时 120s 自动拒绝
☑ 七场景集成测试：完整块/拆包/逐字符/deny/批准/拒绝/目录越界/普通代码块不误判
```

> 实现备注：协议用「回复内嵌 estudio-cmd 围栏块」而非 litellm function calling —— 不绑定模型、流式友好、协议可肉眼审计。理由记录在案。

### 雷二：IDE 模式骨架

**目标**：学习中心长出眼睛——打开真实项目，在课程树旁看代码。

```
任务清单：
□ 模式切换器（📚 学习 / 💻 IDE），复用三栏玻璃外壳
□ projects.json：项目注册表（{id, name, root, allowed_ops}）
□ 文件树面板：扫描项目根目录，忽略 .git/node_modules 等
□ 只读代码查看器：内置离线语法高亮、行号、基础排版
□ 文件系统 API：受限读写（仅项目根内）
```

**交付物**：在 IDE 模式打开一个项目，左栏是文件树，中栏看代码，右栏继续和 AI 聊。

### 雷三：标记器系统（核弹）

**目标**：让 AI 讲解的每一行代码都有档案——聊天 ↔ 代码双向标记，持久化。

```
任务清单：
□ 标记数据模型：marker = {id, file, lines, note, chat_message_id}，持久化到项目数据
□ AI 侧：讲代码时产出结构化标记（file:line + 讲解摘要）
□ 代码查看器 gutter：标记点渲染 + hover 浮层 + 点击跳转聊天
□ 聊天消息内嵌 [📄 file:line] 徽标：点击跳转编辑器并高亮
□ 会话结束后标记保留，下次打开项目仍在
```

**交付物**：学完一章，代码里的标记像荧光笔一样留着；三个月后回来，点击标记还能看到当时的讲解。

## 开发原则

1. **每个 Phase 产出一个可用的东西**，不追求一步到位
2. **数据模型往前看**：design for v1.0, code for v0.1
3. **所有关键逻辑让 AI 先出原型，你来审查、调试、理解**
4. **不要为了"完美架构"而迟迟不动手**——面条代码可以先跑，下一版再重构
5. **你是在用这个工具学编程，写这个工具的过程本身就是项目实战**
